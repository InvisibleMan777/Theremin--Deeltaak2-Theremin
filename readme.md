Deeltaak 1 - Verkeersmonitor

Made by Sem Overbeek as asignment of Windesheim. The goal of the project was to create an electronic theremin, using sensors and actuator to simulate the workings of the instrument. There is an LCD connected that shows the sensor measurments and the frequenty being played. It is also possible to change the filtersize, used to filter out the sensor measurments, the selected filtersize is shown on a 7 segment display.
Project Structure

    src/ - Source code files
    lib/ - Internal libraries
    include/ - External libaries
    docs/ - Documentation

Getting Started

    Clone the repository.
    Open with PlatformIO IDE.
    Make sure everthing on your device is connected as specified in docs/technish_ontwerp.pdf
    Upload to your device.

Requirements

    PlatformIO
    Compatible hardware (found in docs/technish_ontwerp.pdf)
